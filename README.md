### 🏛️ [DevMeet Egypt (Event-Hub)](https://github.com/ahmed-Basal/Event-Hub)
Full-stack platform for tech meetups and events. The API follows Clean Architecture with MediatR pipeline behaviors (validation, logging, tracing, metrics). It has JWT with refresh tokens, API versioning, health checks, OpenTelemetry, Docker Compose, unit tests, and a GitHub Actions CI pipeline.

### 🛒 [Shopping E-Commerce API](https://github.com/ahmed-Basal/shopping-asp-main-main)
Online-store backend: ASP.NET Identity auth, JWT with rotating refresh tokens in HttpOnly cookies, Redis shopping basket, Stripe checkout, product catalog with paging, search and reviews, custom rate limiting, security headers, global exception handling, Swagger docs. Uses the Repository and Unit of Work patterns.

### 🎬 [VidPulse (YouTube-Clone)](https://github.com/ahmed-Basal/YouTube-Clone)
Video platform built as a modular monolith. Separate modules for users, videos, channels, interactions and administration, with CQRS and domain events through MediatR, and a database context per module. Video uploads go through Cloudinary.
